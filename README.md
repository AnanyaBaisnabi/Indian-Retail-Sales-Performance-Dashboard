# Indian-Retail-Sales-Performance-Dashboard
Interactive Tableau dashboard analyzing 100,000 retail transactions across Indian states ,regions, and product categories to identify sales trends, profitability drivers, and regional performance patterns.

## Objectives
- Analyse overall sales performance
- Identify high-performing products and regions
- Examine profitability trends
- Compare sales across different segments
- Identify actionable business insights
